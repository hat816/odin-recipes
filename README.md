# odin-recipes
Este es un proyecto para practicar y validar el conocimiento adquirido en HTML

Aprendizaje adquirido:
1. Hacer encabezados.
2. Hacer listas ordenadas y desordenadas.
3. Insertar links e imágenes.
4. Definir propiedades como HEIGHT Y WIDTH para las imágenes y describirlas en ALT = "TEXTO DESCRIPTIVO DE LA IMAGEN".
5. Añadir a los link propiedades para la seguridad de la web y del usuario como: <!-- target="_blank" rel="noopener noreferrer"> -->
5. Hacer párrafos.
